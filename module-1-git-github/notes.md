## Key vocabulary (in your own words)

- repository: A folder/project that Git keeps track of. It contains the project's files and its history of changes.
- commit: A saved snapshot of the changes I made to my project. It is like creating a checkpoint that I can return to later.
- branch: A separate version of a project where I can work on changes without affecting the main version right away.
- push / pull: Push sends my local commits from my computer to GitHub. Pull gets changes from GitHub and brings them to my computer.
- pull request: A request asking other people to review my changes and possibly add them to the main branch.
- merge conflict: A problem that happens when Git finds changes to the same part of a file that it cannot automatically combine. Someone has to decide which changes should stay.
